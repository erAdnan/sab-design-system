# Firebase iOS configs (per variant)
#
# Place downloaded GoogleService-Info.plist files here:
#
# | File | Bundle ID |
# | --- | --- |
# | `GoogleService-Info-demoapp.plist` | `com.sabdesignsystem.demoapp` |
# | `GoogleService-Info-sb.plist` | `com.sabdesignsystem.sb` |
#
# Xcode build phase `Copy GoogleService-Info.plist` selects the correct file
# based on configuration (Debug/Release vs Debug-SB/Release-SB).
#
# Android uses a single `android/app/google-services.json` that already
# contains both application IDs.
